# 01. Java Thread

## 대표 면접 질문

> **Q. Java에서 새 Thread를 시작할 때 start()와 run()의 차이는 무엇인가요?**

**30초 답변:** `Runnable`에 작업을 정의하고 `Thread`에 전달할 수 있습니다. `start()`는 새 Thread가 `run()`을 실행하도록 스케줄링합니다. `run()`을 직접 호출하면 호출한 현재 Thread에서 일반 메서드처럼 실행됩니다. `join()`은 대상 Thread의 종료를 기다립니다.

**핵심 키워드:** Runnable · Thread · start · run · join · 실행 순서

## 개념

| 요소 | 역할 |
| --- | --- |
| `Runnable` | 실행할 작업 |
| `Thread` | 작업을 실행할 흐름 |
| `start()` | 새 Thread 시작 |
| `run()` | 작업 내용. 직접 호출하면 현재 Thread에서 실행 |
| `join()` | 대상 Thread의 종료 대기 |

## Java 예제

```java
public class Main {
    public static void main(String[] args) throws InterruptedException {
        Runnable task = () -> {
            // worker Thread가 실행할 작업
            System.out.println(Thread.currentThread().getName());
        };

        Thread worker = new Thread(task, "worker");
        worker.start(); // 새로운 Thread에서 작업 시작
        worker.join();  // worker 종료까지 main이 대기
        System.out.println("main 종료");
    }
}
```

`worker.start()`가 반환된 직후 worker와 main 중 어느 쪽이 먼저 실행될지는 보장되지 않습니다. 이 예제에서는 `join()` 이후의 `main 종료` 출력만 worker 종료 후에 실행됩니다.

## 앞선 주제와 연결

운영체제에서 Thread는 실행 흐름입니다. Java에서 `Thread`와 `Runnable`로 그 흐름과 작업을 표현합니다. 앞에서 배운 동시성은 실행 순서를 보장하지 않으므로 공유 데이터를 다룰 때 다음 주제인 **Race Condition**을 고려해야 합니다.

## 꼬리 질문과 답

- `worker.run()`을 직접 호출하면 새 Thread인가요?
  - 아니요. 호출한 Thread가 그 메서드를 실행합니다.
- `start()` 직후 worker의 작업이 즉시 완료되나요?
  - 보장되지 않습니다. 완료를 기다리려면 `join()` 등을 사용합니다.

## 핵심 정리

**Runnable = 작업, Thread = 실행 흐름.** 새 흐름은 `start()`로 시작하고, `join()`으로 종료를 기다립니다.
