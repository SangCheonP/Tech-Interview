# Software Engineering

CS 개념을 실제 개발·협업 상황에 적용하는 면접 질문을 묶습니다.

- [ ] 표시 항목은 **작성 예정 문서의 틀**입니다. 관련 개념을 한 문서로 묶고, 본문이 완성되면 링크와 [x]로 바꿉니다.

- [ ] 01. 좋은 코드와 객체지향 설계 — 응집도·결합도, SOLID, 리팩터링 판단
- [ ] 02. 디자인 패턴 — Singleton의 장단점, Factory·Strategy의 사용 이유
- [ ] 03. 테스트 — 단위·통합 테스트, 테스트 더블, TDD와 회귀 테스트
- [ ] 04. Git 협업 — commit·branch·merge·rebase, 충돌 해결과 코드 리뷰
