# Network

웹 요청이 전달되는 과정을 이해하기 위한 네트워크 기초를 학습합니다.

비슷한 개념을 묶은 **작성 예정 문서** 목록입니다. 작성된 문서에만 링크를 추가합니다.

- [ ] 01. 네트워크 계층과 주소 — OSI·TCP/IP, IP·Port, Socket
- [ ] 02. TCP와 UDP — 연결 수립·종료, 흐름·혼잡 제어, 신뢰성과 선택 기준
- [ ] 03. DNS에서 HTTP 요청까지 — 이름 해석, Request·Response, Method·Status, 멱등성
- [ ] 04. HTTPS와 인증 상태 — TLS, Cookie·Session·JWT, HTTP 캐시

브라우저의 동일 출처 정책과 CORS는 [Spring Web](<../../Framework/Spring/Web/README.md>)에서 다룹니다.
