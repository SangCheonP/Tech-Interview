# Java 기초

Java 웹 개발 면접에서 언어 기능을 이유와 함께 설명하는 순서입니다.

- [ ] 표시 항목은 **작성 예정 문서의 틀**입니다. 관련 개념을 한 문서로 묶고, 본문이 완성되면 링크와 [x]로 바꿉니다.

- [ ] 01. 객체지향과 클래스 — 캡슐화·상속·다형성, 접근 제어자, 오버로딩·오버라이딩, final
- [ ] 02. 객체의 동등성과 타입 — ==·equals·hashCode, 불변 객체, String, Wrapper, 오토박싱
- [ ] 03. Generic과 Collection — 제네릭의 목적·타입 소거, List·Set·Map과 구현 선택
- [ ] 04. 예외와 자원 관리 — checked/unchecked, try-with-resources, 예외 전파
- [ ] 05. Annotation과 Reflection — 어노테이션의 역할과 런타임 활용
