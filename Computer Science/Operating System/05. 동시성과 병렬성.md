# 05. 동시성과 병렬성

## 대표 면접 질문

> **Q. 동시성과 병렬성은 어떻게 다르며, Thread가 두 개면 항상 병렬로 실행되나요?**

**30초 답변:** 동시성은 여러 작업이 한 기간에 겹쳐 진행되는 성질입니다. 코어 하나에서도 실행 대상을 전환해 구현할 수 있습니다. 병렬성은 같은 순간에 둘 이상의 작업이 실제로 실행되는 것이며 여러 실행 자원이 필요합니다. Thread를 두 개 만들었다고 병렬 실행이 보장되지는 않습니다.

**핵심 키워드:** 작업의 진행 · 실제 동시 실행 · CPU 코어 · 스케줄링 · 전환 비용

## 개념

| 구분 | 동시성 | 병렬성 |
| --- | --- | --- |
| 관찰 | 여러 작업이 진행 | 여러 작업이 같은 순간 실행 |
| 코어 하나 | 번갈아 실행 가능 | 같은 순간 두 CPU 작업 실행 불가 |
| 여러 코어 | 가능 | 서로 다른 코어에서 가능 |

코어 하나가 A와 B를 번갈아 실행해도 두 작업은 **동시적**으로 진행됩니다. 코어가 여럿이면 A와 B가 실제로 **병렬** 실행될 수 있습니다. 병렬 실행도 여러 작업이 함께 진행한다는 의미에서는 동시성에 포함됩니다.

## Java 예제

```java
public class Main {
    public static void main(String[] args) throws InterruptedException {
        Thread a = new Thread(() -> work("A"));
        Thread b = new Thread(() -> work("B"));

        a.start(); // 두 작업을 실행 가능하게 만든다.
        b.start();
        a.join();  // 두 작업이 끝날 때까지 기다린다.
        b.join();
    }

    static void work(String name) {
        for (int i = 0; i < 3; i++) {
            // 출력 순서는 실행 환경에 따라 달라질 수 있다.
            System.out.println(name + ": " + i);
        }
    }
}
```

두 Thread의 작업은 겹쳐 진행할 수 있지만, 이 출력만으로 두 코어에서 실제 병렬로 실행됐는지는 판단할 수 없습니다.

## 앞선 주제와 연결

04번의 **Context Switching**은 한 코어에서 여러 Thread의 작업을 번갈아 진행하게 합니다. 코어가 여럿이면 전환과 함께 실제 병렬 실행도 가능해집니다. Thread 생성·전환·동기화 비용 때문에 작업을 나누면 언제나 더 빨라지는 것은 아닙니다.

## 꼬리 질문과 답

- 단일 코어에서도 동시성이 가능한가요?
  - 네. 실행할 작업을 교체하면서 여러 작업을 진행할 수 있습니다.
- 멀티 코어면 항상 성능이 좋아지나요?
  - 아니요. 작업 특성과 스케줄링, 동기화 및 분할 비용에 달려 있습니다.

## 핵심 정리

**동시성 = 함께 진행**, **병렬성 = 같은 순간 실행**. 여러 Thread를 만들면 병렬성이 보장되는 것은 아닙니다.
